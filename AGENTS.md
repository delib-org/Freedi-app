# Project instructions

For every task in this repository, read and follow the root `CLAUDE.md` before
starting work. Treat it as the shared source of project instructions, and read
the current file rather than relying on a copied summary.

When working in a subdirectory, also read and follow any `CLAUDE.md` files along
the path from the repository root to that directory. More specific instructions
take precedence within their scope. For example, work under `apps/agora/` must
also follow `apps/agora/CLAUDE.md`.

Keep project guidance in the applicable `CLAUDE.md` files so it stays consistent
across agents.
